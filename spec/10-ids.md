# 10 · ID 契约

## 格式

- 类型：**UUID v7**。
- 文本形式：小写、带连字符，36 字符，例如
  `01924f8e-7b3c-7a1d-9f2e-3c4b5a6d7e8f`。
- 生成方式：`onebox_id_generate()`（C）/ `onebox_core::generate_id()`（Rust）。

## 为什么是 UUID v7

- **全局唯一**：不依赖中心分配，跨模块、跨设备可合并。
- **按时间有序**：前 48 位是以毫秒为单位的 Unix 时间戳，天然单调递增，
  适合作为事件日志的排序与分页依据。

## 不可动摇的规则

1. ID 一旦生成，**永不改变**。
2. 同一实体的 ID 在所有事件中保持一致。
3. 核不重用 ID，也不允许调用方指定 ID（事件场景见 `20-events.md`）。

## 返回值与内存

`onebox_id_generate()` 返回核分配的 C 字符串。调用方必须用
`onebox_string_free()` 释放。传入 NULL 安全；同一指针只能释放一次。
